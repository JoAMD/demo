**Edge highlighting (D-09, CANV-03):**
- In the `edges` array passed to ReactFlow, add `style` and `animated` properties:
  - If both `edge.source` and `edge.target` are in `executedIds`: 
    - `animated: true`
    - `style: { stroke: '#f97316', strokeWidth: 2 }` (accent color from UI-SPEC)
  - Otherwise:
    - `style: { stroke: '#2a2a2a', strokeWidth: 1 }` (border color, muted)
- React Flow's built-in `animated` prop uses a marching-dots animation. Per UI-SPEC, we want marching-ants (dashed). Use custom edge styling instead:
  - `style: { stroke: '#f97316', strokeWidth: 2, strokeDasharray: '5 5' }` for executed edges
  - Add CSS `@keyframes march` in index.css or use inline animation via `style`:
    - Actually, React Flow `animated: true` gives us animated dots. For dashed marching ants, we need CSS animation on the edge path.
  - Simplest approach (ponytail): use `animated: true` on executed edges + `style: { stroke: '#f97316' }`. React Flow handles the animation. This is "animated blue line" per CANV-03, but we use orange per D-09.
  - If the user wants true marching-ants dashed animation, that requires custom edge component — skip for now, React Flow's built-in animation is sufficient.

**Node styling (D-10):**
- Pass `executedIds` set to StepNode via `data` property:
  - `data: { label, kind, executed: executedIds.has(step.id) }`
- StepNode uses `executed` to apply muted styling when false

**Performance:** Memoize the edge styling computation with `useMemo` depending on `results`. The `flowToGraph` result + edge styling should be in one memo.

- Get `setSelectedStep` from store: `const setSelectedStep = useTraceStore(s => s.setSelectedStep)`
- Add `onNodeClick` handler to `<ReactFlow>`:
