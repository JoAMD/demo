## Color

| Role | Value | Usage |
|------|-------|-------|
| Dominant (60%) | `#0f0f0f` | App background, canvas background |
| Secondary (30%) | `#1a1a1a` / `#1e1e1e` | Panel backgrounds (`sidebar`), cards, inspector rows |
| Accent (10%) | `#f97316` | Path animation stroke, "Run Trace" button bg, active step highlight border, resize handle hover |
| Destructive | `#ef4444` | Error text, error state background tint, FAIL pill |

Accent reserved for:
1. Path highlight animation (orange dashed stroke)
2. "Run Trace" button background
3. Active step border-left highlight in inspector
4. Resize handle hover state
5. Email preview toggle active state

Success (`#22c55e`): PASS pill background tint, success states only.

Text hierarchy:
- `text-primary` (`#ffffff` dark / `#18181b` light): headings, step names, email subject
- `text-secondary` (`#a1a1aa` dark / `#71717a` light): labels, timestamps, unexecuted steps, helper text

## Visual Hierarchy

Primary anchor: animated orange trace path on canvas — draws eye first.
Secondary: Step Inspector detail card — active step border + PASS/FAIL pill.
Tertiary: JSON Editor — muted, user interacts but doesn't stare.
Panel reopen button: labeled with `aria-label="Open {panel name}"` for accessibility.

## Interaction Contracts

### Keyboard Navigation
| Shortcut | Action |
|----------|--------|
| `ArrowLeft` | Previous step in inspector |
| `ArrowRight` | Next step in inspector |

Only active when step inspector is visible and a trace has been run.

### Panel Resize
- Drag handle on panel right edge (Step Inspector) and right edge (JSON Editor)
- Cursor changes to `col-resize` on hover
- Minimum widths enforced: Step Inspector 240px, JSON Editor 280px
- Maximum widths enforced: Step Inspector 480px, JSON Editor 640px
- Default widths: Step Inspector 320px, JSON Editor 384px

### Panel Close/Reopen
- Toggle button in panel header (× icon or chevron)
- Close hides the panel; canvas takes remaining space
- Reopen via button in header bar (small icon button)

### Path Animation
- **Style:** CSS `stroke-dasharray` + `stroke-dashoffset` animation (marching ants)
- **Color:** `#f97316` (accent)
- **Speed:** `2s linear infinite` for continuous march
- **Stroke width:** 2px
- **Note:** May switch to static in future — see `.planning/CONCERNS.md`

### Step Selection
- Click a node on canvas → inspector jumps to that step's detail card
- Click prev/next buttons → inspector cycles through steps in order
- Active step highlighted with left border accent color
