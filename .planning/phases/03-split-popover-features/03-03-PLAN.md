**Add Export button in header (per D-06, D-07, D-08):**

Add an Export button to the header, positioned LEFT of the Run Trace button.

1. Create a `handleExport` callback:
   ```typescript
   const handleExport = useCallback(() => {
     if (!flow) return;
     const exportData = { flow, payload, results };
     const blob = new Blob([JSON.stringify(exportData, null, 2)], { type: 'application/json' });
     const url = URL.createObjectURL(blob);
     const a = document.createElement('a');
     a.href = url;
     a.download = `${flow.name.replace(/\s+/g, '_').toLowerCase()}_trace.json`;
     a.click();
     URL.revokeObjectURL(url);
   }, [flow, payload, results]);
   ```

2. Add the button in the header div, before the Run Trace button:
