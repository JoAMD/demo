  <behavior>
    - executeTrace returns TraceResult with results array for each step
    - Linear flow (trigger → email → email) produces 3 StepResults
    - Branching flow evaluates split filters and takes correct branch
    - Split with eq predicate: "cart_abandoned" eq "cart_abandoned" → yes branch
    - Split with gt predicate: numeric comparison coerces to Number before compare
    - Split with contains predicate: substring match on string values
    - Empty payload with split → filter fails → no branch taken
    - All StepResults have correct stepId and kind matching source step
  </behavior>
  <action>
Create `src/engine/executionEngine.ts` per D-05, D-06, D-07, D-08.

1. Import types from `./types`
2. Export pure function `executeTrace(flow: Flow, payload: Record<string, unknown>): TraceResult`
3. BFS implementation:
   - Initialize queue with `flow.trigger` as first step
   - While queue not empty: shift step, evaluate, push result, enqueue children
   - Split steps: enqueue ALL children from `step.yes` or `step.no` based on `result.branchTaken`
   - Email/webhook/sms/trigger: no children to enqueue
4. `evaluateStep(step, payload)` function:
   - Switch on `step.kind`
   - Email/webhook/sms/trigger: return `{ stepId, kind, passed: true }`
   - Split: evaluate filters, set `branchTaken: 'yes' | 'no'`, always `passed: true`
5. `evaluateFilters(filters, payload)` function (D-06, D-07):
   - All filters must pass (AND logic)
   - Get nested value from payload via `getNestedValue(payload, filter.name)`
   - Inline switch on `filter.predicate`: eq, neq, gt, lt, contains
   - Loose coercion: String() for string predicates, Number() for numeric
6. `getNestedValue(obj, path)` helper:
   - Split path by `.` and traverse object
   - Return undefined if path not found

Also create `src/engine/executionEngine.test.ts` with tests for:
- Linear flow: 3 steps produce 3 results
- Branching flow: split evaluates correctly
- Filter predicates: eq, neq, gt, lt, contains
- Loose coercion: string "123" compared to number 123 via gt
- Empty payload: split fails to no branch
