  <action>
Create `src/components/JsonEditor.tsx` per EVT-01, UI-SPEC Copywriting Contract, and Layout Skeleton.

1. Import `useState`, `useCallback` from `react`
2. Import `useTraceStore` from `../store/traceStore`
3. Import `useShallow` from `zustand/react/shallow`
4. Import `executeTrace` from `../engine/executionEngine`

**State:**
- `jsonText: string` — raw textarea value (local state)
- `parseError: string | null` — validation error message
- Read `flow`, `status` from traceStore via `useShallow`

**JSON Validation:**
- On every change: try `JSON.parse(jsonText)`, catch error
- If valid: call `setPayload(parsed)`, clear `parseError`
- If invalid: set `parseError` to "Invalid JSON — fix syntax to run trace" (UI-SPEC)
- Debounce not needed — parse on every keystroke is fine for small payloads

**Run Trace button:**
- Disabled when: `parseError` is not null OR `status === 'running'` OR `flow` is null
- Label: "Run Trace" (idle), "Running…" (running) — UI-SPEC Copywriting Contract
- On click: call `executeTrace(flow, parsedPayload)`, set `results` and `status` in store
- `aria-label="Run trace evaluation"` (UI-SPEC Accessibility)

**Textarea:**
- `<label htmlFor="json-editor">Event Payload</label>` (UI-SPEC Accessibility)
- `id="json-editor"`
- Placeholder: "Paste event payload JSON here…" (UI-SPEC Copywriting Contract)
- `font-mono text-[13px]` (UI-SPEC Typography)
- `bg-card border-card rounded-lg` (UI-SPEC Color tokens)
- `aria-invalid="true"` when `parseError` is set
- Red border when `parseError`: `border-error` (#ef4444)

**Layout** (UI-SPEC Layout Skeleton):
- Container: `w-96 flex flex-col gap-4 p-4`
- Textarea: `flex-1 min-h-[200px] resize-y`
- Error text below textarea: `text-error text-xs`
- Helper text: "Edit and click Run Trace to evaluate" — UI-SPEC Copywriting Contract
- Button below helper text
