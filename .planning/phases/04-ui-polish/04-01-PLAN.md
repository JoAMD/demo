**Icon glyphs by kind** (heroicons-style paths, inline SVG, no library — rejects @mui/icons-material):
- **trigger** → calendar (rect + grid lines)
- **email** → envelope (rect + fold line)
- **split** → diverging arrows (4 paths, rotated 90° CW conceptually — user referenced MUI AltRouteIcon rotated 90°)
- **webhook** → chain link (2 interlocked arcs)

All glyphs share `fill="none" stroke="currentColor" strokeWidth="1.5" strokeLinecap="round" strokeLinejoin="round"`. Component sets these on the wrapper `<svg>`. `currentColor` lets StepNode control color via `text-node-*` utility class.

**Implementation sketch:**

```tsx
import { memo } from 'react';
import type { ReactNode } from 'react';

const PATHS: Record<string, ReactNode> = {
  trigger: (<><rect x="3" y="4" width="18" height="16" rx="2" /><path d="M3 10h18M8 2v4M16 2v4" /></>),
  email: (<><rect x="2" y="4" width="20" height="16" rx="2" /><path d="m2 7 10 6 10-6" /></>),
  // ponytail: split = diverging arrows, visually similar to MUI AltRoute rotated 90° CW
  split: (<><path d="M6 3v6m0 0L3 6m3 3 3-3M18 21v-6m0 0 3 3m-3-3-3 3" /></>),
  webhook: (<><path d="M13.19 8.688a4.5 4.5 0 0 1 1.242 7.244l-4.5 4.5a4.5 4.5 0 0 1-6.364-6.364l1.757-1.757m9.193-3.34a4.5 4.5 0 0 0-6.364-6.364l-4.5 4.5a4.5 4.5 0 0 0 6.364 6.364l1.757-1.757" /></>),
};

export const NodeIcon = memo(function NodeIcon({ kind, className = 'w-4 h-4' }: { kind: string; className?: string }) {
  // ponytail: fall back to webhook icon instead of crashing on unknown kind
  const glyph = PATHS[kind] ?? PATHS.webhook;
  return (
    <svg xmlns="http://www.w3.org/2000/svg" fill="none" viewBox="0 0 24 24" strokeWidth={1.5} stroke="currentColor" className={className}>
      {glyph}
    </svg>
  );
});
```

```ts
  if (step.kind === 'split') {
```

NEW:
```ts
function addEdge(sourceId: string, targetId: string, _label?: undefined, sourceHandle?: string) {
  const executed = executedIds.has(sourceId) && executedIds.has(targetId);
  edges.push({
    id: `${sourceId}-${targetId}`,
    source: sourceId,
    target: targetId,
    ...(sourceHandle ? { sourceHandle } : {}),

    style: executed
```

Remove all `label`, `labelStyle`, `labelBgStyle`, `labelBgPadding` properties — user explicitly asked for edge arrow labels removed.

**Why `sourceHandle`:** After Task 3 added split node with `id="yes"` (left) and `id="no"` (right) handles, edges MUST specify which handle to connect from. The arg name is `_label` (underscore prefix) because the only caller in the existing code passes `undefined` for non-split edges, and we keep the param position to minimize diff churn. Cleaner: use a single optional options object. **Ponytail: keep positional args with `_label`, this is a 4-file plan, not the time to refactor argument style.**

**Also update the trigger→step edge call (line 95):** `addEdge(parentId, step.id)` — third arg is now `_label`, fourth is `sourceHandle`. Existing call passes only 2 args, so both new args default to `undefined`. No change needed at the call site.
